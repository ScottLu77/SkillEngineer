# 工程藍圖：meeting-minutes

## 身分

| 項目 | 內容 |
| ---- | ---- |
| 工作情境 | 遷移 |
| 目錄 | `skills/meeting-minutes` |
| name | `meeting-minutes` |
| description | 當要從會議逐字稿產生會議紀錄時，必須使用本 skill。只需要逐字稿摘要而不需要決議與待辦事項時改用 transcript-summary。 |

## SOP 大綱

### Phase 1 -- 理解會議內容

1. `READ` 會議逐字稿與與會者名單。
2. `THINK` 整理逐字稿中明確說出的決議與待辦事項。

完成條件：已列出本次會議的決議與待辦事項。

### Phase 2 -- 產出與驗證

1. `WRITE` 產生會議紀錄；每項決議必須寫出結論，每項待辦事項必須有單一負責人與日期格式的期限。
2. `CHECK` 逐列確認會議紀錄的待辦事項都有負責人與期限；未通過時回到步驟 1。

完成條件：會議紀錄已寫入，且所有待辦事項都有負責人與期限。
