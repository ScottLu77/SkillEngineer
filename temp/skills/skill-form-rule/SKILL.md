# SOP

## Phase 1 -- 理解與設計

1. `READ` 使用者需求，以及要修改的目標 skill 的 `SKILL.md` 中 SOP 流程載入的 RuleFile and TemplateFile (不存在就略過)，確認要修改的目標 RuleFile。
2. `READ` 本 skill 的 `rules/RuleFile-rule.md` 的所有 Rule，建立完成檢查清單。
3. `THINK` 依已載入的完成檢查清單，確定每個 RuleFile 的主題與 Rule 清單。

完成條件：已確定目標 RuleFile 與 Rule 清單。

## Phase 2 -- 寫入與驗證

1. `WRITE` 依已載入的完成檢查清單修改目標 RuleFile。
2. `CHECK` 逐條驗證完成檢查清單；若有任一項未通過，修正後重新檢查。

完成條件：所有檢查項目均已通過。
