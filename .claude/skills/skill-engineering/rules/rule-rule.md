## Rule 1 -- Rule 標題行的寫作規則

- MUST: 每個 Rule 標題行的格式為 `## Rule <編號> -- <抬頭>`。
- MUST: <編號> 從 1 開始連續編號。
- MUST: <抬頭> 的格式為 `<產出物或其部分的名稱>的寫作規則`。

## Rule 2 -- Rule 清單項目的寫作規則

- MUST: 每條 Rule 清單項目 (以下稱 MUST 細則) 的格式為 `- MUST: <必須遵守的細則>`。
- MUST: 兩位審查員只看產出物各自檢查 <必須遵守的細則>, 會得到相同的是或否判定。
- MUST: 每條 MUST 細則只寫一個要求。
