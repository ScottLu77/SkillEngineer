## Rule 1 -- 約束清單的寫作規則

- MUST: 每一項的格式為 `<約束原文> -> <放置位置>`。
- MUST: 約束原文來自使用者或舊 skill 時, 保留原本用字。
- MUST: 由 AI 推導的約束, 開頭標 `[推導]`。
- MUST: 放置位置只能是 `SOP` 或 `rules/<主題>-rule.md`。
- MUST: 規範流程或執行行為 (含步驟順序、分支、結束點) 的約束, 放在 `SOP`。
- MUST: 只規範 skill 寫出的檔案或 ASK、TELL 訊息的內容或格式的約束, 放在 `rules/<主題>-rule.md`。
- MUST: 兩者都有的約束拆成兩項。
